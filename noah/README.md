# Les versions de Noah

Le canal des versions **de Noah**, le coach formateur de l'équipe, conçu par Devlogy.

Noah évolue sur son **instance zéro**, chez Devlogy. Chaque nouvelle version est annoncée ici. Les instances des clients lisent ce canal : leur admin voit la note de version en premier, puis l'applique en une phrase à Claude, avec le plugin Noah.

- [`versions.json`](versions.json) : le fichier lu par les instances des clients ;
- [`CHANGELOG.md`](CHANGELOG.md) : le même journal, à lire.

Dernière version : **2.0.0** (2026-10-30).
